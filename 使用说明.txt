【一、这是什么】
------------------------------------------------------------
这是一个直接注入游戏进程的"内置式"修改器（基于 UE4SS 脚本框架，
与大型 MOD 圈通用同一套技术）。它以悬浮菜单形式显示在游戏画面里，
效果与商用外挂一致，但完全工作在本地，不修改游戏文件本体。

功能总览：
  ◆ 状态锁定   —— 锁血(上帝模式)/锁饥饿/锁口渴/锁耐力/锁感染/
                  锁体温/锁电量，全部一键锁定，数值不再下降
  ◆ 状态修改   —— 生命/饥饿/口渴/耐力/感染/体温/电量 任意补满
  ◆ 一键补满   —— 全部状态拉满 + 清除流血/感染等异常
  ◆ 物品生成   —— 736 种游戏物品全量可刷（均为游戏数据表中逐项
                  验证过的真实物品代码），分10大类：
                  全部/远程武器/近战武器/弹药箭矢/食物饮品/
                  医疗药品/材料资源/服装装备/工具杂物/其他·特殊
                  含全部弹药变体（7.62/5.56/.308/45ACP/357/12G 及
                  穿甲/燃烧/碎裂弹）、全部服装、车辆升级件、
                  枪械配件、技能书、挂饰等
                  搜索：菜单内直接输入字母/数字实时过滤（如 ak、762）
                  数量：选中物品后进入数量选择页（1~200，默认10）
                  列表显示中文名称（附代码名对照）
                  刷出后物品掉落在人物面前的地上，屏幕提示
                  "已掉落在面前: 名称"，走过去拾取即可
  ◆ 僵尸生成   —— 33 种怪物：普通丧尸、狂奔者、巨力、巨型、变异、
                  军装重甲、僵尸熊、僵尸鹿、僵尸狗 等
                  （生成功能仍在调试中，如遇无效请等待更新）
  ◆ 车辆生成   —— 38 种可驾驶车辆：吉普/皮卡/SUV/轿车/掀背/跑车/
                  警车/装甲车/货车/面包车/房车等，生成在面前指定
                  距离处（←→调整距离）
  ◆ 世界控制   —— 时间加减、天气切换、移动速度 1x~5x
  ◆ 悬浮界面   —— 实时状态面板 + 分类菜单 + 操作提示

【二、按键一览】（全部为不与游戏冲突的按键）
------------------------------------------------------------
  打开/进入 菜单：
    小键盘 +      或    大键盘 =      ← 进入/确认（菜单关闭时按=直接打开主页）
  返回/退出 菜单：
    小键盘 -      或    大键盘 -      ← 返回上一层 / 关闭菜单
  （原"小键盘0 / 小键盘."进出按键已全部移除）

  快捷功能键（小键盘 1-9 与 大键盘 F1-F9 完全等效）：
    小键盘1 / F1     主菜单         小键盘2 / F2     上帝模式
    小键盘3 / F3     一键补满       小键盘4 / F4     状态全锁
    小键盘5 / F5     物品生成       小键盘6 / F6     僵尸生成
    小键盘7 / F7     世界控制       小键盘8 / F8     状态面板
    小键盘9 / F9     调试转储
    （车辆生成：打开菜单 → 选"车辆生成器"）

  菜单内操作：
    ↑ ↓          上下选择 / 列表滚动
    PgUp/PgDn    列表翻页
    ← →          调整数值（数量页 / 车辆距离 / 开关）
    字母/数字    物品列表内 = 搜索输入；DEL 删除字符
    小键盘 + 或 =   确认（进入分类 / 选定物品→选数量→生成 / 执行）
    小键盘 - 或 -   返回上一层 / 清空搜索 / 关闭菜单

  操作示例（刷狙击枪）：
  按 = 或 小键盘+ 打开菜单 → 选"物品生成器" → 按 + 进入 →
  选"远程武器" → 按 + 进入 → 直接输入 awm 搜索 →
  ↑↓选中 AWM → 按 + → ←→把数量调到10 → 按 + 生成，
  物品掉落在人物面前地上。

【三、安装方法】
------------------------------------------------------------
方法一（推荐）：
  1. 把本文件夹（解压后的 HTZ修改器_v2.3）整个放在游戏根目录
     （与 "HumanitZ" 文件夹同级）；
  2. 双击运行 "一键安装.bat"，等待提示"安装成功"；
  3. 正常启动游戏。

方法二（手动）：
  把 payload 文件夹里的全部内容复制到
     HumanitZ\Binaries\Win64\  覆盖同名文件即可。

注意：如游戏内没有反应，请检查以下文件是否被杀毒软件删除：
     HumanitZ\Binaries\Win64\dwmapi.dll（核心，必须存在）

【四、使用说明】
------------------------------------------------------------
  1. 启动游戏并读取存档进入世界（进入主菜单后稍等几十秒，
     修改器会自动完成"就绪"与属性校准）。
  2. 屏幕左上角会出现【状态面板】：实时显示七项状态数值，
     锁定中的项目带 [锁] 标记。
  3. 按 小键盘1 打开彩色菜单（主菜单界面上则以屏幕顶部文字形式提示）。
  4. 首次进入后建议：按 小键盘4 开启状态全锁 + 小键盘2 上帝模式。

  数值含义说明：
   · 感染 0  = 未感染（健康状态）
   · 体温 37 = 正常体温（摄氏度）
   · 生命/耐力/饥饿/口渴/电量 满值 100

【五、故障排查】
------------------------------------------------------------
  Q1. 游戏里没有提示、按键没反应？
      → 检查 HumanitZ\Binaries\Win64\ 下是否存在 dwmapi.dll 和
        UE4SS.dll（很可能被杀毒删除，添加信任后重装）。
      → 查看 Mods\HTZ_Trainer\htz_log.txt 是否有"初始化完成"。

  Q2. 某个功能无效？
      → 把 Mods\HTZ_Trainer\htz_log.txt 提供给作者，
        通常一次小更新即可修复。

  Q3. 按键冲突？
      → 优先用小键盘；如仍冲突，可在游戏中改绑其它按键。

  Q4. 游戏偶发闪退？
      → 经对照实验（完全不加载修改器长时间运行）确认：闪退与
        修改器无关，为注入框架与游戏本体的兼容性问题，
        不影响存档数据，遇到后重新进入游戏即可。

  Q5. 游戏启动不了（双击原启动器无反应/一闪而过）？
      → 新版 Windows 的"智能应用控制(SAC)"可能拦截了原启动器
        steamclient_loader_x64.exe。解决办法：
        改用游戏根目录下的 HumanitZ.exe 启动游戏
        （或使用本包附带的"启动游戏.bat"）。

  Q6. 游戏自带的快捷栏/人物状态不见了？
      → 这是游戏自带的 HUD 显示开关被按到了：它的默认键是
        【Backspace（退格）】。再按一次 Backspace 即可恢复显示。
        （修改器的搜索删除已改用 DEL 键，不会再误触。）

【六、卸载方法】
------------------------------------------------------------
  双击运行 "卸载.bat"（只删除修改器）。
  彻底还原：删除 Win64 下的 dwmapi.dll、UE4SS.dll、
  UE4SS-settings.ini 和 Mods 文件夹即可，游戏本体未被改动。
